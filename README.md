# Nexgen

**The world wide code hub for builders and open source.**

Nexgen is an independent open source developer platform led by **Shibli Sanjid Faheem**. It brings code discovery and AI-assisted development together: find public projects, open a local workspace, build with the model and tools you choose, then share your work with the community.

## Nexgen today

- Search public GitHub repositories from the home page
- Work with AI across terminal, desktop, and browser interfaces
- Connect model providers, tools, and configurable agents
- Keep projects and session data in your local workspace
- Extend the platform through its TypeScript client, server, protocol, and SDK packages

The current repository explorer sends searches to GitHub. Nexgen does not yet host Git repositories or accounts of its own. Hosted collaboration and community services will be added here as the project grows.

## Run Nexgen locally

This is a Bun workspace. Install the pinned Bun version, then run:

```sh
bun install
bun run dev
```

The existing CLI executable and internal package scopes retain their `opencode` names for compatibility while Nexgen's distribution services are established.
